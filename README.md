# 🧮 Calculadora em Python - Imersão Alura

Projeto de calculadora simples em linha de comando (CLI) desenvolvido durante a **Imersão Python da Alura**. A aplicação realiza as operações matemáticas básicas com validação de dados e prevenção contra divisão por zero.

---

## 🚀 Funcionalidades

- **4 Operações Básicas:**
  - Adição (+)
  - Subtração (-)
  - Multiplicação (*)
  - Divisão (/)
- **Validação de Entrada:** Verifica se a opção digitada no menu é válida antes de pedir os números.
- **Tratamento de Exceções:** Mensagem de aviso caso o usuário tente dividir por zero.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3

## 💻 Como Instalar e Rodar no Windows

Siga o passo a passo abaixo para rodar a aplicação na sua máquina:

### 1. Instalar o Python no Windows
Caso ainda não possua o Python instalado:
1. Acesse o site oficial: [python.org/downloads](https://www.python.org/downloads/)
2. Baixe e abra o instalador mais recente.
3. ⚠️ **MUITO IMPORTANTE:** Na primeira tela de instalação, marque a opção **"Add python.exe to PATH"**.
4. Clique em **Install Now** e aguarde a finalização.

### 2. Baixar o Código do Projeto
- Clique no botão verde **Code** no topo desta página e selecione **Download ZIP**.
- Extraia a pasta baixada no seu computador.

### 3. Executar o Programa
1. Abra a pasta onde está o arquivo `calculadora.py`.
2. Clique na barra de endereços do Explorador de Arquivos (no topo da janela).
3. Digite `cmd` e aperte **Enter** (isso abrirá o Prompt de Comando na pasta).
4. No terminal, execute o comando:
   ```bash
   python calculadora.py
   ```
*(Se não funcionar, tente digitar `py calculadora.py`).*
